## ✨ التحديثات الجديدة المنفذة:

1. **تحسين أسلوب الخربشة (Realistic Scratch Feel):**
   - إضافة شظايا ورق الذهب المتطايرة (**Scratch Gold Flakes Physics**) التي تتطاير وتسقط بالجاذبية عند الخربشة بالعملة.
   - تنعيم ضربات الفرشاة مع مسارات متصلة وتفتت واقعي لحواف الفويل الذهبي.
   - إضافة عملة ذهبية تتبع حركة الماوس (**Coin Cursor Follower**).

2. **أنيميشن فانكي مضاعف (Ultra Funky Vibe):**
   - استيكرات متحركة عائمة على جوانب الشاشة (`💥 طاقة العالمية 💥`، `👑 بطل الأبطال 👑`).
   - عناصر ديكورية متحركة تدور وتطفو في الخلفية (`⚡ ⭐ 🪙 🔥 💥 🎉`).
   - أنيميشن اهتزاز ومطاطية للأزرار والكروت عند التفاعل.

3. **نسبة الخربشة 70% وإلغاء النصوص القديمة:**
   - تم تعديل نسبة الكشف المطلوبة لتصبح **70%** كما طلبت.
   - تم مسح عبارة "خربش 50%" من الكارت بالكامل.
   - تم مسح مؤشر النسبة المئوية والأرقام أسفل الكارت واستبداله بـ **شريط الحماس التفاعلي** بدون أي نسب مئوية.

4. **طبقة التمويه والبلور (Mystery Blur Layer):**
   - ما تحت الكارت يظهر عليه بلور قوي (20px Blur) مع شارات وأقفال سرية 🔒 تمنع تماماً معرفة هل هي جائزة أم حظ أوفر أثناء الخربشة.

5. **مرحلة الساسبينس والتشويق الناري (The Suspense Phase):**
   - عند الوصول لنسبة 70%، يبدأ الساسبينس لمدة 2.2 ثانية:
     - اهتزاز درامي للكارت بالكامل مع إضاءة نيون قوية.
     - مؤثر صوتي سينمائي (ضربات قلب وطبول متسارعة مع نغمة تصاعدية Riser).
     - عد تنازلي ناري: `3 ... 2 ... 1 ... 💥`
     - انفجار بصري ومؤثر Crash يفك البلور فوراً ويظهر المفاجأة!

6. **صياغة رسالة الفوز بالاسم:**
   - في حالة الفوز تظهر الرسالة بالصيغة المطلوبة:  
     **`مبروووك المكسب يا [الاسم] يا بطل العالمية! 🏆🎁🎉`**
   - في حالة الحظ الأوفر:  
     **`حظك وحش يا نجم استنانا ف مسابقات جاية 💪🔥`** مع أنيميشن عضلات تفاعلي.
